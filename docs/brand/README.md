## 概念

构型不变（详见几何一节）：

- **火焰 = favicon 原焰的进化**——圆弧底泪滴，尖端迎风右上挑起；火心为负形（透底）；
- **W = 护手**——圆头 W 波形，中峰为托焰平台，两端与火焰最宽处对齐；
- **T = 桅杆**——锥度长柄自平台下挺立；迎风举炬、向上拼搏。

v10 的变化在质感与色彩：**整标只有橙色一个色相**——火焰全标最亮、体块深橙、底色奶油纸或深可可，
火心与构件间隙全部用负空间表达。单色相的明度阶梯逼出了更干净的形——不需要装饰，剪影本身就是标志。

## 色板（日光橙单色相，全部平涂，无光晕）

> 橙色为主色调：**整标只有橙色一个色相**，靠明度阶梯而不是多色堆叠——
> 火焰全标最亮（主色），体块次深，底色最深/最浅。教训记录：不用「卡中间」的浊橙，
> 明度拉开才通透。

## 使用规则

- **只允许同一色相**：橙色系深浅组合（奶油纸 → 亮橙 → 深橙 → 深可可）；任何场景不得再加黑、白、第三色相、渐变、光晕、投影。
- **净空**：图形四周留白 ≥ 火焰宽度的一半（512 网格的 92）。
- **最小尺寸**：徽标 24px；32px 起作 favicon；低于 48px 用徽标形态而非透明图形。
- **单色场景**：`torchwood-mark-mono.svg`，CSS `color` 控制颜色。
- 品牌语境需要暖色氛围时，可用旧版「林火」色系文件（git 历史 v9）作为营销物料变体，
  产品界面与默认资产一律使用本双色系统。
