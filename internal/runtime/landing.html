开源后端平台

Torchwood 是一个 AI/Agent-Native 的后端即服务（BaaS）平台：用户认证、文档数据库、 文件存储、函数执行与实时事件开箱即用。Protobuf + OpenAPI 定义的机器可读 API， 让 LLM Agent 与自动化从第一天起就是一等公民。

打开 Admin Console → /.well-known/torchwood

AI-NATIVE BACKEND AS A SERVICE

一个平台，后端全栈

自设计的 API 与工具链同时面向人与机器——控制台点得动，Agent 也调得通。

Agent 原生 API

Protobuf 是唯一事实来源，自动产出 gRPC、HTTP 与 OpenAPI；细粒度 scope 的 API Key 供 Agent 与自动化安全调用 Server API。

用户认证

邮箱、OAuth2、OTP、Magic URL、匿名会话与 TOTP MFA；JWT access/refresh 轮换与会话管理开箱即用。

文档数据库

schema-per-database 的 PostgreSQL 文档存储：行级 RLS 权限、文档级 _acl、Appwrite 风格查询与向量近邻检索。

文件存储

S3/MinIO 兼容：上传下载、在线预览与缩略图、分片断点续传、公开 bucket 与 HMAC File Token。

函数执行

Docker 构建与运行，同步/异步执行；事件触发器把平台事件接进业务逻辑，保留策略自动清理历史。

实时事件

基于 outbox 的全局有序事件流：WebSocket 订阅、断线重连与游标续传，UI 与 Agent 永远追得上数据。

为机器而建，也为人类所用

每个 Torchwood 实例都在 /.well-known/torchwood 公开能力目录， 配合 OpenAPI 描述，Agent 一次抓取即可发现全部 Server API 并以 scoped API Key 直接调用—— 无需人肉翻文档。
